# Közreműködés / Contributing

[Magyar](#magyar) · [English](#english)

## Magyar

Köszönöm, hogy érdekel a projekt!

### Kódhozzájárulást nem fogadok el

A projekt nyílt forráskódú, a [GNU General Public License v3.0](LICENSE) licenc
alatt, de **kódhozzájárulást nem fogad el**. A teljes kódot a projekt tulajdonosa
írja és tartja karban.

- **A pull requesteket a rendszer automatikusan lezárja**, átnézés nélkül.
- Kérlek, issue-ban vagy hozzászólásban se küldj **kódot vagy javítást (patch-et)**.
  Írd le inkább szavakban a problémát vagy az ötletet.

### Így segíthetsz

- **Hibajelentés.** Nyiss egy issue-t: mi történt, mit vártál, és hogyan lehet
  előidézni a hibát.
- **Ötletek, fejlesztési javaslatok.** Nyiss egy issue-t, és írd le, mi lenne
  az ötlet, és miért lenne hasznos.
- **Forkolás.** A GPL-3.0 alapján szabadon forkolhatod, módosíthatod és
  terjesztheted a projektet, a licenc feltételei szerint.

Köszönöm a megértést!

## English

Thank you for your interest in this project!

### Code contributions are not accepted

This project is open source under the [GNU General Public License v3.0](LICENSE),
but it is **not open to code contributions**. All code is written and maintained
by the project owner.

- **Pull requests are closed automatically**, without review.
- Please **do not include code or patches** in issues or comments. Describe the
  problem or idea in words instead.

### How you can help

- **Report bugs.** Open an issue that explains what happened, what you expected,
  and the steps to reproduce it.
- **Suggest features or improvements.** Open an issue that describes the idea
  and why it would be useful.
- **Fork the project.** Under GPL-3.0 you are free to fork, modify, and
  redistribute it on the terms of that license.

Thanks for understanding!
