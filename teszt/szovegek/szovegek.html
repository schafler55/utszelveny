Every text the app shows, by screen. Type in a box to change a text; your changes stay in this browser. Copy changes gives a short list you can send to Claude, who puts them into the app. Download index.html gives the whole app file with your changes in it, which you can upload to GitHub (Add file → Upload files) to replace index.html.
Keep the {placeholders} – the app fills them in (road number, distance…). HTML tags such as <b>…</b> or <br> stay as they are. Units (km, m, km/h), version numbers and road / county names from the data are not in this list.
